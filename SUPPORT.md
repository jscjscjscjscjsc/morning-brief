# Support

## Reporting Issues

If you encounter a problem or have a suggestion, please:

1. **Check existing issues**: Visit [our issue tracker](https://github.com/jscjscjscjscjsc/morning-brief/issues) to see if someone has already reported it.

2. **Open a new issue**: If your problem is new, [create an issue](https://github.com/jscjscjscjscjsc/morning-brief/issues/new) with:
   - A clear title describing the problem
   - Steps to reproduce (if applicable)
   - Expected vs actual behavior
   - Your environment (OS version, OctoSense version)
   - Screenshots or logs if available

## What to Report

We welcome reports about:
- **Bugs**: Crashes, incorrect behavior, or unexpected errors
- **Data issues**: News sources failing to load, incorrect parsing
- **AI behavior**: Unexpected editorial decisions, refusal-to-publish logic issues
- **UI problems**: Layout issues, unresponsive controls
- **Privacy concerns**: Any behavior that seems to violate our [privacy policy](PRIVACY.md)

## What NOT to Report

Please do not use this channel for:
- **Content complaints**: We do not editorialize sources; all headlines come from Hacker News and TechMeme
- **AI output quality**: The app uses your device's LLM provider; editorial style is intentional
- **Feature requests for upstream dependencies**: Issues with OctoSense itself should go to the [OctoSense repository](https://github.com/OctoSense-org)

## Response Time

This is a hackathon project maintained by a small team. We aim to:
- Acknowledge new issues within 3 days
- Provide updates on critical bugs within 1 week
- Address privacy/security issues immediately

## Privacy & Security

If you discover a security vulnerability, please **do not** open a public issue. Instead, email us at the address in our [privacy policy](PRIVACY.md) with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
