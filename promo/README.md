# 宣传片（promo）

本目录存放晨报卡对外的两版宣传视频。点击文件名即可在 GitHub 内置播放器中直接观看。

## vB · 真实演示版（2 分 9 秒 / 1080p，2026-10-14）

- 文件：`vB_real_demo_1080p.mp4`（1920×1080，30 fps，129 秒，H.264 / AAC）
- 封面：`vB_real_demo_cover.png`
- **全部产品画面来自本地 card-host 原生界面真实录制**：采用单帧连续捕获，每章录制约 5 秒、后期保留末帧配合讲解；等待过程做了节选，不是连续实时录屏。
- 讲解为本机合成的中文语音 + 逐句字幕，配乐为原创程序合成。
- **片中数据是真实的一期日报**：本次真实取数得到 80 条原始条目、16 条候选，三位编辑（技术 / 行业 / 读者）背靠背独立评审后，主编终审选出 7 条；终审后的界面更新触发脚本预算保护，独立录制实例重启后从刚生成的 `last_brief.json` 恢复，形成 10/14 11:40 的日报 —— 片中头版与阅读页就来自这一期。
- 录制使用独立录制实例，**未修改主项目代码、未改动任何原始存档**。
- 诚实声明（原样保留）：片中 AI 新封面、新闻配图、采访草稿生成、语音识别与实际分段朗读、完整自然语言工具调用、跨期预测回访、更正与矛盾检测、休刊、收藏与检索等，展示的是**操作入口与机制说明，没有逐项演示成功结果**。在线配音当次返回 403，故使用本机 Microsoft Yaoyao 语音。

## vA · 破晓 · 编辑部叙事版（75 秒 / 720p，2026-10-13）

- 文件：`vA_poxiao_narrative.mp4`
- **纯代码生成**（Python + ffmpeg + numpy 合成音乐）的叙事短片，用于赛事 issue 提交，队伍：共创。
